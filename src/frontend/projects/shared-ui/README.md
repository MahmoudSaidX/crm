# @squad-crm/shared-ui

Shared PrimeNG presentation setup: the single place the PrimeNG theme and
configuration are defined for every Squad CRM surface.

Behavior-free by design — it must not depend on `@squad-crm/platform` or on any
application, and it deliberately does **not** wrap PrimeNG components. See
[the workspace README](../../README.md) for boundaries and usage.
